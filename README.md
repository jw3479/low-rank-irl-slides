# Scalable multi-task inverse reinforcement learning

Interactive research presentation, including animations and speaker notes.

**[Open the slides](https://jw3479.github.io/low-rank-irl-slides/)**

Open the GitHub Pages website, or download `index.html` and open it in a browser.
The deck is self-contained and works offline.

Controls: left/right arrows to navigate, **F** for fullscreen, **O** for overview,
and **N** for speaker notes. Links to individual slides use `#page-8`, for example.

This repository contains the published deck. To update it from the original local
project after rebuilding `IRL_slides.html`, run:

```sh
python3 src/publish_slides.py
```

GitHub Pages publishes the `main` branch from the repository root.
